EARTH-DAY.JPG — NASA Blue Marble (no-clouds variant)
======================================================

This file is a NASA Blue Marble Earth surface map.

Source       : NASA Visible Earth ([visibleearth.nasa.gov](http://visibleearth.nasa.gov)) — the Blue Marble:
               Next Generation collection by Reto Stöckli, NASA Earth
               Observatory (NASA Goddard Space Flight Center).
License      : Public domain. NASA imagery is generally free to use without
               restriction. Standard NASA attribution applies.
Working file : 4096×2048 cloudless Blue Marble derivative (~1.4 MB).
Mirror used  : raw.githubusercontent.com/turban/webgl-earth (used because
               eoimages.gsfc.nasa.gov was not reachable from the build
               sandbox at scaffolding time).
